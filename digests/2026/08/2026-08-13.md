### AI-1. 安全研究披露专有模型推理块曾可被跨上下文滥用

**类型：** 安全研究预印本与负责任披露 · **领域：** 推理轨迹、API 安全、隐私、提示注入 · **证据状态：** 尚未同行评审；论文公开，但未发布攻击代码或敏感数据，供应商据作者称已在披露后采取缓解措施 · **置信度：** 中

**核心进展：** 研究者发现，部分模型 API 返回给客户端并允许后续请求回传的加密或签名 reasoning block，当时可跨会话、用户，甚至同一供应商的不同模型复用。论文称，他们扫描并解码了 315,320 个公开推理块，聚合发现 367 个个人信息痕迹和 182 个凭据痕迹；敏感内容没有随论文公开。

**技术要点与重要性：** 这类块若没有绑定用户、会话、模型和前序消息，保护推理内容的封装仍可能成为跨上下文泄露与提示注入通道。论文讨论把这些上下文纳入 AEAD associated data、使用哈希链或服务端状态等缓解方向，对提供“可回传但不可读”状态的 API 设计有直接启示。

**局限与待验证：** 实验针对 2026 年 7 月初可用的 API；作者称多家供应商确认收件后，同样攻击已无法再次发动，因此不能写成当前仍可利用的零日。论文没有明文思维链真值，只能用 token 数等间接信号判断转录保真，也没有外部独立复现。截至 09:08，Hugging Face Papers 显示 86 个 upvotes、3 条评论，只能说明该平台内关注较高。

### AI-2. Pydantic AI 修补本地 Agent Web UI 的高危跨源请求漏洞

**类型：** 开源框架安全修复 · **领域：** 智能体、浏览器边界、本地工具、审批 · **证据状态：** 官方 GHSA、修复版本和补丁公开；未见版本专项独立安全审计 · **置信度：** 高

**核心进展：** Pydantic AI 2.28.0 与 1.107.4 修复了 `Agent.to_web()` / `clai web` 聊天端点未校验 `Content-Type` 的问题。官方公告称，开发者运行本地 Web UI 并浏览恶意页面时，跨源普通请求可能绕过 CORS 预检触发 agent；后果取决于 agent 暴露的工具和本地凭据。修补版在解析请求体和运行 agent 前强制要求 `application/json`。

**技术要点与重要性：** 默认绑定 loopback 并不自动阻止浏览器向本机服务发请求；客户端代传审批结果也不能替代服务端授权边界。官方将问题评为 High、CVSS 7.6，影响 `pydantic-ai` 与 `pydantic-ai-slim` 的指定 1.x 和 2.x 版本区间。

**局限与待验证：** 利用需要本地 Web UI 正在运行且用户访问恶意页面，并非所有 Pydantic AI 部署都受影响。升级后，直接调用端点的非浏览器客户端需要发送正确 JSON header。仓库截至 09:08 累计约 19,256 stars、2,510 forks，但这是生态规模，不代表漏洞或补丁已被独立验证。

**原始资料：** [GitHub Security Advisory](https://github.com/pydantic/pydantic-ai/security/advisories/GHSA-h4xc-3qfq-jf93) · [v2.28.0 release](https://github.com/pydantic/pydantic-ai/releases/tag/v2.28.0) · [修复 PR #7382](https://github.com/pydantic/pydantic-ai/pull/7382)

### AI-3. Cohere 发布 2.4B 开放权重视觉语言模型 North Micro Vision

**类型：** 开放权重多模态模型 · **领域：** OCR、文档理解、视觉定位、多语 · **证据状态：** 官方模型卡、Apache-2.0 权重与微调配方公开；指标为 Cohere 自评，未见独立复现 · **置信度：** 中

**核心进展：** North Micro Vision Instruct 由约 2B 的 North Micro 语言模型与约 400M、从 SigLIP2 SO400M 起训的原生分辨率视觉编码器组成。模型把多层视觉 patch 表示注入语言模型早期层，支持多图、OCR、文档、图表和视觉定位；语言模型标称 128K 上下文，但官方说明多模态训练与验证只到 8K。

**技术要点与重要性：** 2.4B 规模与原生分辨率路径瞄准可本地部署的文档和视觉理解。Cohere 在统一 VLMEvalKit 中自报 DocVQA val 0.921、ChartQA test 0.808、RefCOCO 平均 0.732、MMMU 0.329；比较表也显示它并非所有任务领先，数字不能外推到真实生产场景。

**局限与待验证：** 模型不是 reasoning 模型，数学、代码、工具调用和 agentic workflow 不是强项；超过 8K 的多模态输入属于未验证外推，原生分辨率也会随图像尺寸增加显存和延迟。当前示例要求 Transformers 5.16.0，正式包可用性与 vLLM 支持仍待完善。截至 09:08，模型页显示 56 likes、98 downloads，并在 Hugging Face 单一平台内出现早期关注。

**原始资料：** [官方模型卡](https://huggingface.co/CohereLabs/North-Micro-Vision-Instruct) · [Cohere 技术文章](https://huggingface.co/blog/CohereLabs/meet-north-micro-vision-instruct) · [NVIDIA AutoModel 微调配方](https://github.com/NVIDIA-NeMo/Automodel/tree/main/examples/vlm_finetune/cohere_micro_vision)
