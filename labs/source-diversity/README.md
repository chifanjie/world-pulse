# 来源航图（Source Diversity Desk）

来源航图是 World Pulse 的首个可交互实验。它把每日 JSON 中的事件、地区和来源链接汇总成一份可重复生成的静态数据快照，帮助编辑者回答四个问题：

- 日报覆盖了哪些地区？
- 当前引用集中在哪些发布者与来源类型？
- 哪些事件在日报中只记录了一条来源？
- 每条聚合数字能否回到具体事件和原始链接？

页面不依赖框架、CDN 或第三方分析脚本。所有筛选都在浏览器本地完成。

## 生成与更新

在仓库根目录运行：

```powershell
python tools\build_source_diversity.py
```

构建器读取 `data/index.json` 指向的每日 JSON，并覆盖生成 `labs/source-diversity/data.json`。输入不变时，输出字节保持一致；构建器不会写入生成时间或其他运行时噪声。

新增或修正日报后应重新运行构建器。提交前建议执行：

```powershell
python -m unittest tests.test_source_diversity -v
python -m unittest discover -s tests -v
git diff --check
```

## 本地查看

浏览器的 `file://` 页面通常不能 `fetch` 相邻 JSON，因此请从仓库根目录启动一个本地静态服务器：

```powershell
python -m http.server 8000
```

然后打开 `http://localhost:8000/labs/source-diversity/`。

页面支持：

- 按日报日期、内容分区（世界事件 / AI 前沿）和来源类型筛选；
- 查看地区、发布者和来源类型的相对分布；
- 定位单一来源事件并打开原始资料；
- 在可横向滚动的审计表中检查事件与来源；
- 把当前筛选导出为 UTF-8 CSV；
- 使用“重置”恢复完整数据视野。

## 数据口径

- **事件**：每日 JSON `items` 中的一条记录；同一天重复的事件 ID 会使构建失败。
- **分区**：`section: "ai-frontier"` 归为 `ai`，其余条目归为 `world`。
- **来源链接**：同一事件内按规范化 HTTP(S) URL 去重。协议和主机名不区分大小写，片段标识被移除，非根路径末尾的 `/` 被忽略。
- **唯一来源 URL**：在全部日报中按同一 URL 规范化规则去重。
- **单一来源事件**：原始事件在事件内 URL 去重后恰好保留一条来源。来源类型筛选不会改变这一判定。
- **地区覆盖**：一条事件可以计入多个 `regions`；同一事件内重复地区只计一次。
- **分布图**：发布者和来源类型按当前筛选下的来源链接数统计；图表只展示前若干项，明细表和 CSV 保留全部结果。
- **CSV**：一行对应“事件 × 当前可见来源”；没有来源的事件仍输出一行空来源记录。

## 限制

- `regions` 是编辑者填写的自由文本标签，不是标准地理编码；“Global”“Europe”等粒度并不等价，页面也不推断坐标。
- 发布者名称与 `source_type` 继承自日报数据，拼写差异会被当作不同实体；本实验不做模糊合并。
- 来源数量、发布者数量和来源类型多样性都不是事实正确性、来源独立性或报道质量的替代指标。两条链接可能来自同一底层材料。
- “单一来源”是审计提示，不等同于该事件错误；部分一手公告本身可能足以支持有限陈述。
- 页面展示的是最近一次运行构建器时的静态快照，不会自动联网刷新。
- 构建器校验结构、日期与 URL 可审计性，但不会请求链接，也不会判断页面是否仍可访问。

## 文件

- `index.html`：语义化页面结构与无障碍标签；
- `styles.css`：响应式“编辑部地图台”视觉；
- `app.js`：筛选、聚合、表格与 CSV 导出；
- `data.json`：由构建器确定性生成，请勿手工编辑。
