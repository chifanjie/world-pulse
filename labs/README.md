# Labs

这里不定期发布与每日内容相关、可离线运行并带测试的小工具和小游戏。

## 已发布

- [来源航图：来源多样性地图台](source-diversity/README.md)：按日期、栏目与来源类型探索日报的地区覆盖、来源集中度和单一来源事件。
- [脉络时间线生成器](pulse_timeline/README.md)：离线按日期、事件 ID 和类别浏览跨日报的事件脉络。

## 候选方向

- 本周世界新闻问答
- 事件时间线生成器
- 来源地区多样性可视化
- 同一事件的多来源对照器
- 汇率、通胀和能源价格背景解释器

每个实验都必须包含可运行实现、使用说明、最小测试、无障碍检查和已知限制；占位文件不算 lab 成果，也不为增加提交数创建空壳项目。
